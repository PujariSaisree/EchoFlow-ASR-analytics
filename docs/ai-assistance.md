# AI-assisted development declaration

This project is being developed with assistance from a generative AI coding assistant.

AI assistance in the current implementation includes architecture drafting, code generation, debugging, documentation, tests, UI markup, and API wiring.

The project developer remains responsible for problem definition, requirement selection, code review, testing, verifying analytical formulas, and final project decisions.

This declaration should be updated if the balance of human and AI contribution changes. Do not describe AI help as minor if the codebase was substantially assistant-generated.
